# MineServer
CLI Tool for Downloading Minecraft Server 
<h6>I created this CLI Tool for my self to create 2 week minecraft server much faster </h6>


<h3>MineServer Dependencies </h3>
<h5>MineServer uses CURL with not include in Standart Libs means you need to Download it</h5>

<h4>Ubuntu based distros</h4>

```
sudo apt update
sudo apt install libcurl4-openssl-dev
```
<h4>Arch based distros</h4>

```
sudo pacman -S curl
```
<h3>MineServer Compiling</h3>

```
git clone https://github.com/Marhau-devoloper/MineServer.git
cd MineServer
chmod +x build.sh
./build.sh
```
